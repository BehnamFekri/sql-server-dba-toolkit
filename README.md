# SQL Server DBA Toolkit

A practical, production-oriented toolkit for SQL Server Database Administration.

## Focus

- Server and database health checks
- Performance troubleshooting
- DMVs and diagnostic queries
- Backup and recovery
- Database maintenance
- Security and permissions
- Blocking and deadlock investigation
- Monitoring and operational runbooks

## Structure

- `monitoring/` — health checks and diagnostics
- `performance/` — performance troubleshooting
- `backup-recovery/` — backup and restore practices
- `maintenance/` — indexes, statistics and integrity
- `security/` — permissions and security checks
- `troubleshooting/` — incident investigation
- `dmvs/` — reusable DMV queries

## Principles

Production-safe, evidence-based, documented and reversible changes.

## Disclaimer

Examples are generic and sanitized. No confidential hospital, patient, credential or production data is included.
